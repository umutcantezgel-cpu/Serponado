# Security Policy

## Supported Versions

We currently support the following versions of Serponado with security updates:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities to security@serponado.com. We will respond as quickly as possible to address your concern.
