# Security Policy

## Supported Versions

Currently, the latest version of Serponado is supported with security updates.

## Reporting a Vulnerability

We take the security of Serponado seriously. If you discover a security vulnerability in this project, please report it to us confidentially.

**Do not disclose the vulnerability publicly.**

Please email your findings to **security@serponado.com**. We will review your report and respond as soon as possible.
