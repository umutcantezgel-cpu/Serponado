## Reporting a Vulnerability

Thank you for helping keep Serponado secure!

Please report all security vulnerabilities to **security@serponado.com**. We take all security issues seriously and will respond to your report as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**
