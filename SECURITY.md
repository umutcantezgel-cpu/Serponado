# Security Policy

## Supported Versions

Currently, the latest version of Serponado is supported with security updates.

## Reporting a Vulnerability

We take the security of Serponado seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to **security@serponado.com**.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you have not received a reply to your email within 48 hours, or have not heard from us for a week after an update, please reach out to us again.

When reporting a vulnerability, please provide the following information:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact.
- Any other relevant information.

Thank you for helping keep Serponado secure!
