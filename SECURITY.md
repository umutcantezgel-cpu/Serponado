# Security Policy

## Supported Versions

Please see our documentation for currently supported versions.

## Reporting a Vulnerability

We take the security of Serponado seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to **security@serponado.com**.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you're curious about the status of your report, please feel free to email us again.

We ask that you do not share or publish the vulnerability until we have had an opportunity to address the issue.
