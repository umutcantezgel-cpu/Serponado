# Security Policy

## Supported Versions

Please check the project for supported versions.

## Reporting a Vulnerability

We take the security of Serponado seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to **security@serponado.com**.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you have not received a reply to your email within 48 hours, or have not heard from us for a while, please reach out again.
