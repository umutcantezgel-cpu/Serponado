# Security Policy

## Supported Versions

The following versions of Serponado are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Serponado seriously. If you discover a security vulnerability, please do not report it publicly.

Instead, please send an email to our security team at **security@serponado.com**. We will evaluate the vulnerability and work to resolve it as quickly as possible. Please allow us reasonable time to respond before disclosing the issue publicly.
