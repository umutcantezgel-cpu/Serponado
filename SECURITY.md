# Security Policy

## Supported Versions

Currently, there are no supported versions as the project contains only documentation.

## Reporting a Vulnerability

We take the security of Serponado seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to `security@serponado.com`. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
