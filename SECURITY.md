# Security Policy

## Supported Versions

Currently, we support the latest version of Serponado.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report any security vulnerabilities to security@serponado.com. We take all security vulnerabilities seriously and will respond to reports as soon as possible. Do not create public issues for security vulnerabilities.
