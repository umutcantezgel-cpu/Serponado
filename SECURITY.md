# Security Policy

## Supported Versions

Please report vulnerabilities for the latest version of Serponado.

## Reporting a Vulnerability

We take the security of Serponado very seriously.

If you discover a security vulnerability in this project, please report it privately. Do not disclose it publicly until it has been patched.

Please report security vulnerabilities to **security@serponado.com**. We will try to respond as quickly as possible.
