# Security Policy

## Supported Versions

Please check the project documentation to see which versions are currently supported with security updates.

## Reporting a Vulnerability

We take the security of Serponado seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

Please direct all security vulnerability reports to **security@serponado.com**.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you do not receive a response within 48 hours, please follow up to ensure we received your report.

Please do not report security vulnerabilities through public GitHub issues.
