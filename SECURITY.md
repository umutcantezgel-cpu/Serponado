# Security Policy

## Supported Versions

Currently, the latest version of Serponado is supported with security updates.

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability within Serponado, please follow our responsible disclosure policy and report it to us immediately.

Please direct all security vulnerability reports to **security@serponado.com**.

We will acknowledge your report and keep you updated on the progress of a fix. We ask that you do not disclose the vulnerability publicly until we have had a chance to address it.
