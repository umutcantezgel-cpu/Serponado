# Security Policy

## Supported Versions

Currently, the latest version of Serponado is supported with security updates.

## Reporting a Vulnerability

We take the security of Serponado seriously. If you discover a security vulnerability, please report it immediately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please responsibly disclose them by sending an email to:
**security@serponado.com**

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you have any further questions or concerns, please let us know.
